Guía de uso

Instrucciones detalladas

1. Antes de empezar

  1. Abre Hermes desde HTTPS o desde localhost. Los navegadores bloquean el micrófono en páginas HTTP no seguras.
  2. Conecta el micrófono que deseas utilizar y comprueba que el navegador tenga permiso para acceder a él.
  3. Usa auriculares si vas a reproducir una grabación mientras el micrófono permanece activo, para reducir el riesgo de acople.

2. Capturar y amplificar

  1. Ajusta la ganancia. El valor inicial es 15x; si aparece distorsión, redúcelo.
  2. Presiona Iniciar captura y acepta el permiso del micrófono.
  3. Hermes desactiva la cancelación de eco, la supresión de ruido y el control automático de ganancia para aplicar su propio procesamiento.
  4. El medidor muestra el nivel de entrada en tiempo real. No representa una medición calibrada en decibelios.
  5. Presiona Detener y guardar para generar el archivo amplificado.

3. Transcribir

La transcripción se realiza con la Web Speech API y se muestra durante la captura. Esta API utiliza el micrófono nativo del navegador; no recibe el stream amplificado de MediaRecorder. La disponibilidad y el idioma dependen del navegador.

4. Usar Mostrar

  1. Presiona Mostrar. Si no hay una sesión activa, Hermes intentará iniciar la captura y solicitar el permiso del micrófono.
  2. La pantalla se vuelve completamente negra y cada palabra reconocida aparece enumerada en orden.
  3. Presiona Salir, en la esquina superior derecha, para volver al menú principal. La captura permanece activa hasta que la detengas.

5. Reproducir la grabación

Después de detener la sesión, usa los controles nativos del reproductor para reproducir, pausar, buscar y ajustar el volumen del audio amplificado.

Hermes funciona mejor en un contexto seguro HTTPS o en localhost.
